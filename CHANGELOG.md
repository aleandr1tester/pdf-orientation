# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.1.1] — 2026-11-08

### Исправлено

- В карточках пресетов подписи («как в файле», «против часовой», «по часовой»)
  снова идут отдельной строкой под заголовком, а не в одну строку с ним.

## [1.1.0] — 2026-11-08

### Добавлено

- **Пакетный режим**: можно перетащить сразу несколько PDF. Появляется полоса файлов
  с переключением и удалением, галочка «Применять ко всем файлам» и кнопка
  «Скачать всё (ZIP)» — все результаты одним архивом.
- **Автоповорот страниц с повёрнутым текстом**: если текст на странице лежит на боку
  или вверх ногами (в том числе из-за `/Rotate`), приложение само разворачивает
  содержимое и подбирает лист. Отключается галочкой в настройках.
- **Просмотр страницы крупно**: клик по превью открывает страницу с зумом
  (50–400 %) и переключением «Результат / Исходник».
- **Горячие клавиши**: `R` / `Shift+R` — поворот, `A` — альбомный лист, `K` — книжный,
  `Ctrl+S` — скачать, `Esc` — закрыть просмотр, `+` / `−` — масштаб.
- **Аннотации при повороте**: вместе со страницей пересчитываются не только `/Rect`,
  но и `/QuadPoints` (подсветки, ссылки) и `/InkList` (рукописные пометки).
- Предупреждение в сводке, если содержимое после масштабирования обрежется.

### Изменено

- **Умнее автоподбор ориентации**: лист меняется только для «сжатых» широких бланков
  (содержимое занимает почти всю ширину листа, но не всю высоту) и только если
  содержимое заметно увеличится (≥ 8 %). Обычный портретный документ с широкой
  таблицей или баннером больше не разворачивается.
- При автоповороте содержимое сразу вписывается в лист с полями 5 мм.
- В подвале показывается версия приложения.
- JSZip встроен в `index.html`; сборка остаётся одним автономным файлом (~2 МБ).
- README и демо-скриншоты обновлены; все тестовые PDF — синтетические.

### Исправлено

- Поворот аннотаций: раньше внешний вид штампов и подсветок мог не соответствовать
  новому положению страницы.

## [1.0.0] — 2026-11-08

Первый релиз.

- Автоопределение широкого бланка на книжном листе и разворот на альбомный A4.
- Ручные пресеты: альбомный/книжный лист, поворот ±90°, оригинал.
- Форматы A4/A5/A3/Letter, поля, масштаб, обрезка белых полей.
- Предпросмотр результата, выбор страниц, проверка и скачивание.
- Текст остаётся векторным, обработка полностью локальная.
- CI на GitHub Actions, демо на GitHub Pages, автономный `index.html`.
